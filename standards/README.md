# Standards

The standards every change to Spellbook answers to. [`AGENTS.md`](../AGENTS.md) holds the binding decisions and the working rules; these files hold the detail. Where a file here and `AGENTS.md` disagree, `AGENTS.md` wins and the file is corrected in the same commit. The folder follows Isotone's `standards/`.

| File | Covers |
| ---- | ------ |
| [`cpp.md`](cpp.md) | C++ style, naming, layering, errors, logging, Unicode, user data, performance |
| [`ui.md`](ui.md) | The WinUI 3 UI standard: layout, DPI, keyboard, themes, copy, and the theme vocabulary |
| [`testing.md`](testing.md) | Test projects, naming, fixtures, round-trip proofs, the launch smoke |
| [`release.md`](release.md) | Versions, tags, the changelog, artifacts, and the release checklist |
